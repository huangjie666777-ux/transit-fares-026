# 公交换乘规划器

React与TypeScript最小项目，业务功能尚未实现。依赖版本由package-lock.json锁定。

使用WSL已安装的Node.js22.16.0和npm10.9.2。若当前终端尚不能找到Node，先设置工具路径，再在项目目录启动页面：

```bash
export PATH="/home/hj/.local/share/cc-codex/toolchains/node-v22.16.0-case002/node-v22.16.0-linux-x64/bin:$PATH"
npm run dev
```

依赖已安装，重新安装使用`npm ci`。构建使用`npm run build`。Vitest已准备，编写必要测试后使用`npm test`。当前起点没有业务测试，不把空测试集当成通过。

新克隆环境需准备相同版本的Node.js，再运行`npm ci`。
