# 公交换乘规划器

React与TypeScript最小项目，业务功能尚未实现。依赖版本由package-lock.json锁定。

使用Node.js22.16.0和npm10.9.2。若当前WSL终端没有Linux Node工具链，先设置本终端PATH：

```bash
export PATH="/home/hj/.local/share/cc-codex/toolchains/node-v22.16.0-case002/node-v22.16.0-linux-x64/bin:$PATH"
npm ci
npm run dev
```

构建使用`npm run build`。Vitest已准备，编写必要测试后使用`npm test`。当前起点没有业务测试，不把空测试集当成通过。
